# Security policy

Primary Signal has not released a supported version yet.

Please do not open a public issue for a suspected vulnerability. Use the
repository's [private vulnerability reporting
form](https://github.com/mravalanche/primarysignal/security/advisories/new) so
the report and any supporting detail remain private.

Include the affected component, likely impact, and a minimal reproduction when
it is safe to do so. Do not include real credentials, private data, or details
from systems you do not own or have permission to test.
